Specifically checked:

- ZERO requests to hyperschedule.io or coursedog.com. The Hyperschedule link on
  a candidate row is an anchor the STUDENT may click; the page never fetches it.
- ZERO requests to fonts.googleapis.com, fonts.gstatic.com or any CDN.
- The share link is a FRAGMENT (#plan=...). Browsers never transmit a fragment,
  so request 1 is a plain GET of "/" with no plan data in it. Confirmed by the
  address bar: after Replace, the URL is http://localhost:3001/ with no
  fragment at all (AC-F09).
- Export made NO request. The file is built in memory as a Blob and handed to
  the browser through an object URL that is revoked immediately.
- Requests 97 and 98 appear only AFTER a requirement row was expanded, and once
  each despite two rows being opened, because the section and history caches are
  shared across rows.
